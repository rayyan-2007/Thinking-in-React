# Thinking in React - Product Filter App

This is a beginner React project.

It is based on the official React documentation example called **Thinking in React**.

The app shows a product table.  
The user can search products.  
The user can also show only products that are in stock.

---

## What I Learned

In this project, I learned these React concepts:

- Components
- Props
- State
- Controlled inputs
- Event handling
- Rendering lists
- Filtering data
- Using keys in lists
- Passing data from parent to child
- Updating parent state from child component
